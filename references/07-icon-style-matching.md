# 07 · 图标风格匹配规则（参考图驱动 · 两段式）

> **起因**：骨架版图标（单色线性）只是**占位结构**，不是最终视觉；最终图标必须是**彩色**，并经过 **AI 二次绘制 + 上色**，让它更真实、更有质感。
> **本规则解决**：人类给出**模板 / 参考图**后，AI 怎么「**找相似的**」或「**生成相近的**」。
> **状态**：⚠️ **当前不锁定任何风格**——等人类参考图到位后再填 `style-brief`；在此之前骨架版**只用于定"要哪些图标、代表什么"**。
> **版本**：v1.0

---

## 0. 两段式：骨架版 → 定稿版

| 段 | 目的 | 形态 | 谁做 | 现在到哪了 |
|---|---|---|---|---|
| **第一段 · 骨架版** | 定**语义与位置**：需要哪些图标、每个代表什么、挂在哪条信息项 | 单色线性（如 `assets/icons/child_travel/` 现有 18 个） | AI | ✅ 已完成（儿童出行示例） |
| **第二段 · 定稿版** | 定**视觉**：按参考图风格重绘 / 上色 / 加质感 | **彩色**，风格与参考图一致 | AI 出稿 + 人确认 | ⬜ 等参考图 |

> **骨架版不作为最终视觉交付**；保留它的唯一理由是：语义不错、位置不丢，风格可以整批替换。

---

## 1. 风格提取：从参考图里读 8 个维度（`style-brief`）

人类给参考图后，AI **逐张拆解**并填成下表（这就是 `style-brief`）：

| # | 维度 | 取值（择一或写区间） | 怎么读 |
|---|---|---|---|
| 1 | **渲染方式** | 极简线性 / 扁平彩色 / 描边彩色 / 半拟物 / 拟物 3D | 有没有描边？有没有体积感？ |
| 2 | **线条** | 无 / 等宽（给 px）/ 粗细对比 / 手绘抖动 | 量最细与最粗处 |
| 3 | **圆角** | 直角 / 小圆角 / 全圆角 | 看端点与转角 |
| 4 | **视角** | 正视平面 / 等轴 2.5D / 三点透视 | 有没有"厚度面" |
| 5 | **配色** | 主色 Hex + 辅助色 + 饱和度区间 | 吸色统计，写成 `#RRGGBB` |
| 6 | **光影** | 无 / 单光源（写方向）/ 环境光 | 高光在哪一侧 |
| 7 | **质感** | 纯色 / 渐变 / 纸纹 / 半透明 / 金属 | 看表面材质 |
| 8 | **细节度** | 极简（≤20 条线）/ 中等 / 写实（含纹理） | 数元素个数 |

**输出**：`references/05-style-spec.md` 的对应大类里填这 8 项 + 一张"参考图 → 特征"的拆解表。

## 2. 风格谱系 ↔ 图标集合对照表（**实测可用**）

> 这张表是"**找相似**"的索引：参考图落在哪一档，就先去对应档位的集合里找。

| 档位 | 可用集合（本轮实测 HTTP 200） | 视觉特征 | 适合场景 |
|---|---|---|---|
| **① 极简线性** | `tabler` · `lucide` · `phosphor` | 等宽线、无填充、单色 | 骨架版；克制、权威的正式信息 |
| **② 扁平彩色** | **`flat-color-icons`** · `twemoji` · `noto` | 纯色块、无渐变、识别度高 | **公众信息图首选**、儿童/科普 |
| **③ 描边彩色** | `openmoji` | 彩色但带描边，轻松亲和 | 社区活动、亲子主题 |
| **④ 半拟物 / 微立体** | `fluent-emoji-flat` | 扁平 + 轻微层次与阴影 | 需要"高级感"又不失清爽 |
| **⑤ 拟物 / 3D 渐变** | `fluent-emoji` · `emojione` | 渐变、体积、光影 | 需要"写实/更真实"时 |

⚠️ 上表以外的彩色集合也可能是好来源，但**使用前必须核许可**（见 `06-icon-sourcing.md` 第 3 节白名单）。

---

## 3. 「找相似的」三步法

```
第 1 步  同集合内找语义
         参考图 → 判定档位 → 在该集合里搜语义（如 flat-color-icons 里搜 traffic / child）
第 2 步  跨集合按特征筛
         同集合缺图时，换到同档位的另一个集合；仍以 8 维特征为准（线宽/圆角/光影必须接近）
第 3 步  仍找不到 → AI 生成相近的
         用第 4 节的提示词公式生成；生成后仍需过第 5 节一致性校验
兜底      语义优先：宁可用"语义准确 + 风格略偏"的图标，也不要用"风格像但看不懂"的图标
```

**检索技巧**：Iconify 搜索支持限定集合，例如
`https://api.iconify.design/search?query=child&prefixes=flat-color-icons,noto`
拿到候选后，**先看风格是否同档，再看语义**——不要只按语义选。

## 4. 「用 AI 生成相近的」提示词公式

```
[主体] + [视角] + [风格档位与特征] + [材质/质感] + [光源方向]
+ [配色（给 Hex）] + [背景：完全透明] + [输出：PNG 1024px 长边]
```

**一套图标必须追加"一致性后缀"**（否则每张都像另一个世界）：

```
同一套图标，务必保持一致：等宽线条 __px；同一光源（__ 方向打光）；
同一饱和度与色温；同一视角（__）；图标在画布中的视觉占比一致；背景全部透明。
```

**示例（档位 ④ 半拟物，儿童出行 · 红绿灯）**：

```
一个红绿灯图标，正视略 2.5D 视角，扁平 + 轻微微立体阴影（fluent-emoji-flat 那种质感），
圆角矩形灯箱，三个圆形灯位（红/黄/绿点亮状态），塑料与磨砂金属质感，
左上方 45° 单光源，配色 红 #E5484D / 黄 #F2C200 / 绿 #2F855A / 灯箱 #3A4A5A，
背景完全透明，输出 PNG 长边 1024px。
同一套图标保持一致：等宽线条 8px；左上 45° 单光源；同一饱和度；
正视视角；图标在画布中占比一致；背景全部透明。
```

**二次绘制（上色/写实化）时**：允许改变**渲染方式**（线性 → 彩色/微立体），
**不允许改变**：符号语义（禁止斜杠方向、三角 vs 圆形）、预警四色、必含元素。

## 5. 一致性 6 条（多图标并排看，必须全过）

| # | 检查 | 不合格的样子 |
|---|---|---|
| 1 | **厚度/线宽一致** | 有的 2px、有的 8px |
| 2 | **光源方向一致** | 一个左上打光、一个右下 |
| 3 | **饱和度与色温一致** | 一个高饱和荧光、一个灰调 |
| 4 | **视角一致** | 一个正视、一个等轴 |
| 5 | **画布占比一致** | 有的撑满、有的缩成一点 |
| 6 | **风格关键词逐条命中** `style-brief` | 参考图是"清爽"，出来的是"厚重" |

> 校验方式：**并排贴在一张 A3 上**（照 `assets/icons/child_travel/sheet.tex` 的做法），一眼就能看出谁不合群。

## 7. 一页纸

1. **现在只有骨架版**（单色线性）——只用于定"要哪些图标、代表什么"，**不是最终视觉**。
2. 你给**参考图/模板** → 我提取 **8 维风格特征**（`style-brief`）→ 落进 `05-style-spec.md`。
3. 找相似的顺序：**同档位集合内搜语义 → 跨集合按特征筛 → 仍缺则 AI 生成相近的**。
4. 最终图标**必须是彩色**，并经 **AI 二次绘制/上色**让它更真实；**允许改渲染方式，不允许改符号语义**。
5. 多图标必须过**一致性 6 条**，并排看不像一套就退回重做。
6. **风格在你给参考图之前不锁定**——现在改风格不产生返工，因为骨架版是可整批替换的。
