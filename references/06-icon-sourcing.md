# 06 · 图标来源与授权规则

> **解决什么问题**：用户没提供图标时（信号灯、警示牌、锅、厨房、太阳、温度计……），这些图标从哪来、怎么保证**语义不错、风格统一、授权干净**。
> **适用节点**：N6 图形素材统一化（主）· G3 设计系统冻结（确认）· G4 内容与可读性（复核）
> **版本**：v2.0 ｜ 政策来源：方案 1 为主 + 方案 3 补缺 + **AI 二次绘制（彩色 / 写实化）**；警示类强制国标；免费无纠纷的可直接用
> **⚠️ 风格相关请看 `07-icon-style-matching.md`**：本文件管**骨架版**怎么来，07 管**定稿版**长什么样。

---

## 1. 流水线（v2：两段式）

```
【第一段 · 骨架版】只定语义与位置
① 定形状      ② 取图           ③ 登记
国标符号       Iconify 下载      icon-list.md
+ 开源库       SVG → PNG        （标注 骨架版，非最终视觉）

【第二段 · 定稿版】按参考图定视觉（见 07）
④ 风格提取   ⑤ 找相似 / 生成   ⑥ AI 二次绘制上色   ⑦ 一致性校验
style-brief   同档位集合或 AI    彩色 + 更真实        6 条并排比对
```

| 步 | 谁做 | 做什么 | 产出 |
|---|---|---|---|
| **① 定形状** | AI 提名 + 人定 | **警示 / 禁止 / 指令 / 预警色 / 公共信息 / 分类** → 用国标形状；**生活与具象**（太阳、温度计、锅、厨房）→ 选定**一家**开源库 | 图标需求清单（名称 / 含义 / 用在哪条信息项） |
| **② 取图** | AI | Iconify 下载 SVG → 用 `0_生成工具/图标转PNG.py` 转 **PNG**（任意尺寸 / 任意颜色 / 保形状） | `assets/icons/*.png` |
| **③ 确认** | **人** | **Gate 3**：形状对不对、语义有没有歧义、风格是否统一 | `gate3.md` 签字 |
| **④ 美化** | **人（外部工具）** | 用 AI 绘图工具加质感与细节 | 美化后的 PNG |
| **⑤ 登记** | AI | 写进 `icon-list.md`（见第 5 节） | `icon-list.md` |

> ⚠️ **④ 美化有一条硬约束**：**不得改变形状与语义**——禁止斜杠的方向、圆/三角/方形的区别、预警四色，一律照 ② 的形状走。**美化前后必须并排比对**，形状偏差超阈值即退回。

## 2. 能力边界（本轮实测，诚实报告）

| 能力 | 状态 | 说明 |
|---|---|---|
| 从 Iconify 下载开源图标 SVG | ✅ 可用 | 实测 HTTP 200；Tabler / Lucide / Phosphor 等 20 万+ 图标 |
| **SVG → PNG（任意尺寸 / 换色 / 保形状）** | ✅ **自研工具已打通** | `0_生成工具/图标转PNG.py`（SVG→最小 PDF→Ghostscript）；实测 4 个图标 100% 保真 |
| 访问国内站点（iconfont / gov.cn / 国标全文公开系统） | ✅ 可通 | 可用于查标准与授权 |
| 访问 Wikimedia 等境外图库 | ❌ 超时 | 不能作为来源 |
| pip 安装第三方库 | ❌ 沙箱禁止 | 所以转换器是纯标准库实现 |
| **AI 生图（美化那一步）** | ❌ **本环境没有图像模型** | **必须由你们在外部工具完成**；我给"形状锁定约束 + 提示词 + 验收标准" |

**结论**：① ② ③ ⑤ 我全包；**④ 需要你们动手**（或告诉我你们用什么工具，我把提示词和验收标准写好）。

## 3. 图标库白名单（按授权负担排序）

### A 类 · 无需署名，画面上不必写来源（**首选**）

| 库 | 许可 | 说明 |
|---|---|---|
| [Tabler Icons](https://tabler.io/icons) | MIT | 线性统一 2px，数量大；本轮实测用它的 sun / thermometer / alert-triangle / ban |
| [Lucide](https://lucide.dev/) | ISC | 线性、规整，公共服务场景稳 |
| [Material Symbols](https://fonts.google.com/icons) | Apache-2.0 | 面性/线性可切 |
| [Phosphor](https://phosphoricons.com/) | MIT | 六种字重 |
| [Bootstrap Icons](https://icons.getbootstrap.com/) | MIT | 简洁够用 |
| **国标符号**（GB 2894 / GB/T 10001 / GB/T 19095 / 气象预警） | 公开标准 | **形状由标准规定，不得改动**；按标准几何复现不算创作 |

### B 类 · 需署名，**用了就必须在画面上署名**（许可条件，不能省）

| 库 | 许可 | 要求 |
|---|---|---|
| Flaticon / Freepik（免费档） | 需署名 | 海报角落写 "Icons by …"，并在 `icon-list.md` 登记 |
| Noun Project（免费档） | 需署名 | 同上 |
| Storyset 等插画库 | 需署名 | 同上 |

> ⚖️ **必须说清的一件法律事实**：**署名是许可条件，不是可选项。** 用了 CC BY / 需署名的库却不在画面上标注 = 侵权。所以：
> **"不想在画面上写来源" 的正确做法不是省略署名，而是只选 A 类。** 本包默认全走 A 类。

### C 类 · 先查再用（逐图标核验）

| 来源 | 风险 |
|---|---|
| [iconfont（阿里）](https://www.iconfont.cn/) | **逐图标集许可不同**，很多标注"仅限学习交流"→ 用前必须逐个查 |
| 政府网站配图 | 多为"版权所有"，**不可直接商用**；标准**图形本身**可依标准复现 |

### ✗ 红线 · 一律不用

- **付费**图标（未经采购）
- 标注 **"严禁转载 / 未经授权不得使用"** 的任何素材
- **机构徽标、国徽、部委标志、医疗十字、红十字**等受保护标识（**禁止使用，也禁止仿制**）
- 含**可识别人脸**且无肖像授权的照片

## 4. 警示类图标的强制规则（本轮定稿）

| 类型 | 必须 | 禁止 |
|---|---|---|
| 禁止类 | 圆环 + 45° 斜杠（方向：左上→右下），红色环 + 斜杠 | 自绘变形、斜杠反向、用橙色代替红色 |
| 警告类 | 正三角 + 黑色感叹号，黄底黑边 | 用圆形/方形代替三角 |
| 指令类 | 圆形 + 蓝色底 + 白色图形 | 改色、改形状 |
| 气象预警 | **红 / 橙 / 黄 / 蓝** 四级，**颜色不可自定义** | 自创等级色、混用顺序 |
| 垃圾分类 | 四分类名称与色标**按本市标准** | 自创分类色 |

**违反任一条 = Gate 3 直接否决**（这不是审美问题，是语义与合规问题）。

## 5. `icon-list.md` 登记格式（逐图一行）

| 列 | 说明 | 例 |
|---|---|---|
| 图标名 | 文件与语义名 | `sun` |
| 含义 | 它在海报上代表什么 | 高温 / 日晒 |
| 用在 | 哪条信息项 | 行动 2「外出时做好遮阳与防晒」 |
| **来源** | 国标号 或 库名 + 图标 ID | `tabler:sun`（MIT） |
| **授权** | 许可类型 | MIT，无需署名 |
| 是否需署名 | 是 / 否 | 否 |
| 尺寸 / 颜色 | 落版参数 | 512px → 落版 24mm；`#1B2A38` |
| 形状核对 | 是否通过 Gate 3 形状确认 | ✅ 2026-10-01 签字 |

> 校验脚本第 19 项：若存在 `content/<id>/icon-list.md`，检查上表 8 列是否齐备；缺列即报错。

## 6. AI 的默认动作（用户没给图标时）

1. **AI 先补**：按第 1 节流水线 ① ② 直接产出图标与 PNG；
2. **同时出清单**：写 `icon-list.md` 并在 Gate 3 提交；
3. **不得静默更换语义**：找不到合适图标时，**优先换"文字标签"**（如用文字"禁止占用"代替一个看不懂的图形），而不是凑一个含义不清的图标；
4. **缺图时的降级顺序**：国标符号 → 开源库同名图标 → 开源库近似图标（须在清单里写"近似替代"）→ **文字标签**（最后一档）。

---

## 7. 一页纸

1. **形状先定**（国标 + 一家开源库），**再美化**（外部工具），**美化不许改形状**。
2. **授权只走 A 类**（MIT / ISC / Apache / CC0 / 国标公开符号）→ 画面上**不必写来源**；用 B 类就**必须署名**。
3. **警示类强制国标**，违反即 Gate 3 否决。
4. **付费 / 禁止转载 / 未授权 / 受保护徽标** → 一律不用。
5. 工具链：`图标转PNG.py`（SVG→PNG，已实测可用）；**美化那一步需要你们用外部 AI 工具**。
