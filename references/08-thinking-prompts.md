## 组一 · 共享与冻结

### Q1｜15 类共享什么？

**结论：分三层，共享程度不同。**

| 层 | 共享范围 | 具体内容 | 谁能改 |
|---|---|---|---|
| **L1 硬共享** | **15 类完全相同** | 画布规格（A3 297×420 + 3mm 出血）· 安全边距 ≥18mm · 栅格栏宽 242mm · 每行容量（中文 25 字 / 英文 49 字符）· 字号下限（正文 ≥26pt，升档 ≥31pt）· 对比度阈值（≥4.5:1，升档 ≥7:1）· 必含元素（机构标识 + 时效字段 + 求助方式）· 禁止元素（虚构徽标 / 无授权素材） | **不可改**（改即全包返工） |
| **L2 大类共享** | **F1–F5 各一套** | 色彩系统 · 字体（中英文字族与字重）· 图形语言（图标风格档 / 线宽 / 圆角）· 版式气质（留白比例、标题正文比例、是否用色块） | 人（走 G3） |
| **L3 类内独有** | **每类一份** | 主骨架（S1–S9 择一）· 信息项数量与顺序 · 警示强度 · 图标清单 | 人（走 G3 简版） |

**为什么这么分**：信息类海报的第一要务是"**读得对、看得清**"——这部分**必须 15 类统一**，否则居民在两张海报上要重新学习阅读路径；而"**气质**"可以由大类区分（办事要可信、健康要温和、安全要强对比）；真正逐类不同的只有**骨架与信息项**。

**对应条款**：F1 / F2 / F3 / F13（L1）· F17 + `references/05`（L2）· F8 单一主骨架（L3）

### Q2｜冻结在大类层冻一次，还是每类各冻一次？

**结论：两层冻结。**

1. **总冻结（1 次）**：F1–F5 五套 Tokens 同时冻 → 管 L1 + L2
2. **类内轻冻结（每类 1 次）**：只冻该类独有的（骨架 / 信息项 / 警示强度 / 图标清单）→ 走 **G3 简版**（3 分钟，同一张卡勾选项）

**理由**：每类各冻一次 L1/L2 → 会出现"15 套色彩系统"，等于**没有设计系统**；只冻一次且 15 类完全一样 → **D09 的警示强度会被稀释**（安全信息与图书室信息长得一样，是事故隐患）。

### Q3｜冻结与内容谁先？

**结论：先内容后冻结——现有顺序正确（N3 → G2 → N4 → G3），但补一条**：

> **冻结时的压力测试样本 = 信息项最多的那一类。**

字号阶梯与版式容量是按"信息项条数"定的；若按条目最少的那类冻结，后面遇到条目多的类**必然爆版**，只能回头改 Tokens（= 重新走 G3）。

### Q4｜冻结前 AI 到底能不能出图？

**结论：能出"结构"，不能出"风格"。**

| 档 | 内容 | 允许？ |
|---|---|---|
| ✅ 可出 | 线框 / 骨架图（只有区块与文字占位）· 信息项清单 · 母本草稿 · 候选方向的**文字描述** | 是 |
| ⚠️ 可出但必须标注「示意，非冻结值」 | 单张配色/情绪示意图（**仅用于沟通，不进入生产**） | 是（须标注） |
| ❌ 不可出 | **可直接发布的成稿** | 否 |

**一句话判据**：**产物的"可发布性"只能在 G3 之后才具备。**

**理由**：风格未冻结时出成稿 = 出废稿，而且会诱导人"就按这个改改"，把冻结流程架空。

### Q5｜冻结后 AI 权限差在哪？路由判错了算改冻结项吗？

**结论：冻结后 AI 只可"在 Tokens 内执行"，不可"改 Tokens"；并且要区分"风格变更"与"路由更正"。**

| 情形 | 处理 | 是否算改冻结项 |
|---|---|---|
| 冻结后微调（换一行字、移动一个块） | AI 直接做，**不出 Tokens 范围** | 否 |
| 想改色 / 改字体 / 改字号阶梯 | **停**，走 G3 迷你评审（人签字） | **是** |
| **同类内**路由判错（D01 → D02，同属 F1） | 退回 **N2**，骨架与信息项跟着换，**Tokens 不动** | 否（仅骨架变更） |
| **跨类**路由判错（D09 → D05，F4 → F2） | 退回 **N2 + 重走 G1**，Tokens **随大类切换** | 否（属"路由更正"，不是"风格变更"） |

**关键区别**：**"改冻结项"是人的审美决定**（要重新签字）；**"路由更正"是事实纠错**（要重新确认分类，不是重新选风格）。

### Q6｜只填了 3 个大类的风格，剩下 2 类能开工吗？

**结论：能，但只能推进到 N3，且两条硬约束。**

- 已填大类 → 全流程可走
- 未填大类 → **只能走到 N3（事实结构化）为止**；**不得进入 N4（方向候选）**，更不得出图。骨架版图标可先备（占位）
- **硬约束①**：**禁止把已填大类的风格套到未填大类上**（会造成 15 类串味，且违反 F17"AI 不得自行决定风格"）
- **硬约束②**：交付件必须**显式标注"该大类风格待填"**，不得静默交付

**理由**：风格是人类的决定；但"内容准备"与"图标骨架"不依赖风格，可以并行推进，不必空等。

## 组二 · 我们场景里的"副教授写成教授"

### Q7｜下面这些错，算同一类风险吗？

**结论：算，共同名字叫「口径错误」（Error of Commitment）——错一个词就改变了"承诺内容"，居民据此行动会白跑、走错、误期、甚至误判资格。**

| 口径类型 | 例子 |
|---|---|
| **时限口径** | "工作日 9:00–11:30" 写成 "每天"；截止日、有效期 |
| **资格口径** | 临时救助 / 临时补助；低保 / 低边；是否需要本人到场；是否收费 |
| **服务口径** | 流感疫苗 / 新冠疫苗；接种 / 注射；法律援助 / 法律咨询 |
| **空间口径** | 无障碍通道 / 无障碍电梯；楼栋号、入口方向 |
| **紧急口径** | 119 / 110 / 120 落在什么语境 |

**建议**：把这五类做成 **G2 的专项核对维度**（现在 G2 只查"字符级一致"，不足以兜住）。

### Q8｜G2 逐字核对会把错的锁死，怎么办？

**结论：G2 增加一道「官方口径比对」，并把"母本本身有错"定义为升级事件。**

现状问题：G2 只核对"**成品 vs 母本**"——母本错了照样通过。

**建议规则**：G2 增加"对照官方口径"一栏（比对对象 = 政策文件 / 官网 / 公告），三条出路：

| 情形 | 处理 |
|---|---|
| 官方口径查得到 | 以官方为准 → **退回 N1 / N3 更正母本**，记录为「母本更正」 |
| 查不到 | **不得发布** → 转 `needs-human`，由社区确认后再走 |
| 官方与母本都不明确 | 采用**保守表述**（"每天" → "工作日（以官方公告为准）"）——**宁可少承诺，不可多承诺** |

**责任分配**：AI 负责**查**（来源检索与比对）；**人负责确认**（G2 签字时对口径负责）。

### Q9｜要不要单独冻结一张专有名词表？

**结论：要。这是本项目性价比最高的一件事。**

新增 `glossary.md`（专有名词表），在 **G2 冻结**，六列：

| 术语 | 规范写法 | 禁止写法 | 来源 | 可否在正文出现 | 备注 |
|---|---|---|---|---|---|
| 临时救助 | 临时救助 | 临时补助、临时救济 | 民政部文件 | 可 | 与"低保"不是一回事 |
| 法律援助 | 法律援助 | 法律咨询、法律帮助 | 法律援助法 | 可 | 免费，需资格审查 |
| 低保 | 最低生活保障（低保） | 低边、低收入 | 民政部文件 | 可 | 与"低边"是两套口径 |

**冻结后的价值**：脚本可**扫描"禁止写法"**（与现在扫 `{{占位符}}` 残留同一机制）→ **机器可查**。

### Q10｜哪些词绝对不可改写？

**结论：建「禁改词表」（locked-words），四类，只能原样搬运。**

| 类 | 词例 | 为什么 |
|---|---|---|
| **义务类** | 须 / 应 / 应当 / 不得 / 请勿 / 严禁 | 强度不可升降（"请勿涉水"改成"注意涉水"是事故） |
| **条件类** | 凭…办理 / 限… / 仅限 / 需本人到场 / 需提前预约 | 省掉就改变了办理条件 |
| **费用类** | 免费 / 收费 / 自费 / 押金 | 删改即误导 |
| **时间类** | 工作日 / 节假日除外 / 当日 / 提前 N 个工作日 | 模糊即误期 |

**规则**：这些词及其所在句子，**AI 只能原样搬运，改写即 Gate 2 否决**。
**脚本可查**：把词表变成正则，检查成品是否包含母本中出现的**每一个**禁改词（母本有"须"、成品写"需要" → 报错）。

### Q11｜哪些机器能查、哪些必须人看？

**结论：机器管「格式与一致性」，人管「事实与口径」。**

| 检查项 | 机器可查 | 人必须看 |
|---|---|---|
| 电话位数 / 中英两版一致 | ✅ 正则 + 双版比对 | ✅ **号码是否真实可用**（应拨号验证） |
| 时间跨天（22:00–次日 6:00） | ✅ 结束早于开始 → 必带"次日" | ✅ 是否符合官方表述 |
| 地址漏楼栋号 | ⚠️ 只能查"是否含 号/栋/室" | ✅ **地址是否正确** |
| 资格口径（低保/低边） | ✅ 扫术语表禁止写法 | ✅ **是否适用于本社区** |
| 禁改词是否被改写 | ✅ 逐词存在性 | — |
| 紧急号码语境 | ✅ 检查 119/110/120 是否与非紧急词同句 | ✅ **是否真属紧急事项** |
| **职称 / 姓名 / 头衔类** | ❌ 无名单可比 | ✅ **必须人核**（课件原题即此类） |
| 视觉：字号 / 对比度 / 安全边距 | ✅ 实测数值 | ⚠️ 观感另议（组三） |
