## 2. 填写要求（这 5 项各自怎么写才可用）

| 项目 | 合格的写法 | 不合格的写法 |
|---|---|---|
| **风格关键词** | 3 个词，每个附"意味着什么 / 不意味着什么" | "高端大气上档次"（无法判定） |
| **主色与辅助色** | 给 `#RRGGBB`，并写明每个色的**允许用途 / 禁止用途** | "蓝色系"（无法落地） |
| **指定字体** | 字体名 + 字重清单 + 回退字族 + 商用授权结论 | "好看的字体" |
| **必须包含的元素** | 可被**逐条校验**的清单（能写成脚本检查项） | "要显得专业" |
| **明确禁止的元素** | 可判定的禁令（看到就能判"违规"） | "不要太花" |
