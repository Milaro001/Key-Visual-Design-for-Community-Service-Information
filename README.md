## 二·五、v1.4 三条新规则（改了哪些行为）

| 规则 | 内容 | 落点 |
|---|---|---|
| **① 用户指定优先** | 用户明确给出的**信息项、任务概述、输出尺寸、目标受众、事实值**一律优先于本包默认值与冻结值；冲突时改锁 F1/F13 并重算（例：用户给 9:16 → 按 9:16；行数配额与 A3 留白随之重算） | F16 · `references/02` 第 11 节 · `references/03` 第 2.5 节 |
| **② 语言随受众** | 受众含 **A06 新市民与国际居民** → 中英双语；**否则只出中文**，不生成英文母本与英文海报 | F15 · 步骤 2/8 · 校验脚本语言一致性检查 |
| **③ 受众可自拟但须问** | 用户未给受众时，AI 依主题拟定（写明依据）**并主动询问确认**；未确认前标"AI 拟定，待确认" | 步骤 1 · 各包 `theme.yaml` 的 `audience_status` |

**当前 15 类的语言分布**：**仅 D01_service 为双语**（受众含 A06），其余 14 类**只出中文**——英文备用文案仍保留在生成器数据源里，给对应 `audience` 加上 `A06` 再重跑即可启用。

## 四、建议使用方式

1. **交作业要求①（工作流程图）** → `01_工作流程图.png`（矢量打印用 `.pdf`）。
2. **要让别的 AI 接手改图** → 把 `01_工作流程图.mmd` 整段发给它。
3. **要落成可运行的 Skill** → 以 `04_SKILL.md` 作为 `skill/SKILL.md`，`references/` 原样放进 `skill/references/`，`content/` 放进 `skill/content/`，先填齐 15 个 `{{占位符}}`，再按 14 步走。
4. **要换主题 / 换事实** → 改 `0_生成工具/生成内容包.py` 里的数据源 → 重跑 → 再跑校验；**不要手改** `content/` 与 `references/04`（会被自动覆盖）。
5. **要验收** → 打开 `05_物料交付与验收清单.xlsx`，按"交付清单 33 项 / 成品规格 38 项 / Gate 1–5"逐条打勾。
